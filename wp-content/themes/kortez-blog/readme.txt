== Description ==

Kortez Blog is fast, flexible and multipurpose WordPress theme that consists of one pre-built starter template to easily build your websites. This theme is built in elementor which is very popular page builder plugin that requires zero coding and can be customized very easily with lots of customization options.

== Frequently Asked Questions ==

= Does this theme support any plugins? =

Kortez Blog includes support for Elementor, WooCommerce, Breadcrumb NavXT and Contact From 7.
