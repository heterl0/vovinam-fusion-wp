== Description ==

Kenta Yoga Coach is a multi-purpose theme, It's suitable for building Yoga tutorial websites, business websites, personal homepages, blogs, magazines and more. There are many well-designed starter-sites that can be imported by just one click. You can check out the sample websites at https://kentatheme.com/yoga-coach/ or visit https://kentatheme.com/starter-sites/ for more one-click starting websites.
